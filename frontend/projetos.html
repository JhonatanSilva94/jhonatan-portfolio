SprintLaser

Site e sistema de fila para gravação a laser de medalhas em corridas de rua, criado para melhorar o fluxo da gravação e minimizar o tempo das pessoas na fila. O corredor cadastra nome e tempo de prova pelo celular, e o gravador consulta pelo número da camisa o que gravar na medalha.

  • Python
  • JavaScript
  • Terraform
  • Lambda
  • API Gateway
  • DynamoDB
  • S3
  • CloudFront
  • GitHub Actions
